# Security policy

## Supported version

Security and dependency fixes are applied to the latest revision of `main`. Projects generated from an older copy should update their dependencies and review changes from the current starter.

## Report a vulnerability

Email **anubis.chain@proton.me** with:

- `subgraph-starter` in the subject
- the affected file or dependency
- impact and reproduction steps
- any suggested mitigation

Do not open a public issue or publish exploit details before the maintainers have had an opportunity to investigate and coordinate a fix. Never include API keys, deployment keys, wallet secrets, or seed phrases.
